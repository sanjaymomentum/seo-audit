SEO / Finding 01 · Technical SEO

The Website Needs a Stronger SEO Foundation

Google can find the website, but several technical and structural issues make it harder to crawl and understand.

XML Sitemap

No visible XML sitemap was found, making it harder to clearly communicate the site's important pages to search engines.

High Priority

Page Speed

Some pages load slowly and may provide a weaker experience for visitors.

High Priority

Page Structure

Page titles and headings need a clearer structure so Google can better understand each page.

High Priority

HTTPS & Core Web Vitals

HTTPS is in place, but Core Web Vitals performance has not been fully validated.

High Priority

Internal Linking

Related services and pages are not connected strongly enough to guide users and search engines.

High Priority

Mobile UX

Responsive design present but conversion elements (CTAs, click-to-call) need optimisation

Medium Priority

Image SEO

Images need better optimisation, including descriptive alt text and more relevant facility photography.

Low Priority

Why It Matters?

A technically clean website gives Google a clearer path to crawl, understand and rank the right pages.

  1. Ensure key pages can be crawled and indexed
  2. Improve page structure and headings
  3. Strengthen internal links between related pages
  4. Validate performance and technical health
  5. Check performance after changes

Recommended Action

Fix the technical and structural issues first, then re-test the website.

SEO / Finding 02 · Local SEO

Local Visibility Needs Stronger Trust Signals

The Google Business Profile is set up correctly, but there is limited review depth and profile activity.

Google Business Profile

Category is correctly set as “Nursing home”; address, phone, website and hours are complete.

Good

Reviews

5.0 rating with 4 Google reviews. The rating is strong, but the small review count provides limited proof.

High Priority

Profile Activity

No recent Posts or visible Q&A activity; limited fresh profile content.

High Priority

Photos

Limited photo coverage beyond the main profile image.

Medium Priority

Local Signals

Business details should remain consistent across local directories and listings.

Medium Priority

Why It Matters?

A strong local listing is more convincing when there is enough activity, review depth and supporting information behind it.

  1. Build a steady flow of genuine reviews
  2. Keep the profile active with useful posts and Q&A
  3. Add fresh photos regularly
  4. Keep business details consistent across local listings

Recommended Action

Start a review programme, keep the Google Business Profile active with fresh content and photos, and audit local listings for consistency.

SEO / Finding 03 · Content Architecture

Key Service and Location Searches Need Dedicated Pages

The website offers the right services, but key local searches do not have dedicated pages built around them.

Service Pages

Core services need dedicated pages built around specific search intent.

High Priority

Location Pages

Key areas such as Hereford, Kington and Leominster need relevant landing pages.

High Priority

Search Intent

Pages should match what families are actually searching for.

High Priority

Content Depth

Service and location pages should include clear information, FAQs and trust signals.

Medium Priority

Conversion Path

Each page should make the next step clear — enquire, call or book a visit.

Medium Priority

Why It Matters?

Families often search for a specific service or care option in a specific location. Dedicated pages give Google a clear result to show.

  1. Identify priority services
  2. Build relevant location pages
  3. Add useful supporting information
  4. Make enquiry and contact options clear

Recommended Action

Create priority service + location pages, starting with the highest-value search opportunities.
